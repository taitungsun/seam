**Special Education Administration & Management · v1.7**

SEAM 是一套為**高中職特殊教育教師與特教業務承辦人**設計的離線行政工具。整套系統就是一個 HTML 檔案，用瀏覽器開啟即可使用，不需要安裝、帳號、伺服器或網路連線，開啟、操作、列印都不連網，所有資料只存在自己的電腦裡。

它的定位介於「校內 IEP」與「特殊教育通報網」之間：把平時散落在多份 Excel 裡的學生、課表、成績與經費資料集中在一處，讓承辦人能快速掌握重要資訊，作為填報與撰寫 IEP 前的工作底稿。

## 功能模組

| 模組 | 說明 |
|------|------|
| 總覽 | 學生名單（含障礙類別、導師、輔導教師，一鍵快速檢視伴隨障礙與證明效期）、學生分布統計（特教類別／科別／年級）、年度經費執行率、待辦事項；身心障礙證明 90 天內到期自動提醒 |
| 學生資料 | 名冊依年級→班別→座號排序，可依科別、班級、類別篩選；民國年日期輸入（可用日曆選擇）；學籍異動與歷屆封存；去識別化列印；匯出學生名單給 SEIA（特教鑑定評估系統）匯入，預設一年級在學學生 |
| 分組課表 | 課程分組（含學生名單）與教師課表分開管理，列印課表 |
| 成績管理 | 依科目建立成績表，可設定定期評量次數與加權比例；從名冊勾選匯入學生；原住民學生依年級標示及格標準（40／50／60 分）；成績冊列印 |
| 經費管理 | 多年度、多計畫經費追蹤，自動計算執行率與餘額，呈現歷年執行趨勢 |
| IEP 匯出 | 上傳 IEP .odt 模板，自動帶入 20 項學生資料（姓名、特教類別、鑑定文號等）；匯出時選學年度學期，預設下一個要寫的學期 |
| 系統設定 | 學校資訊（學年度學期預設依日期自動判斷）、科系設定、備份與還原、資料使用量、IEP 模板管理 |

## 快速開始

1. 到 [Releases](../../releases) 下載最新版的 `SEAM_v1.7.html`（若要使用 IEP 匯出，請一併下載 `個別化教育計畫_模板.odt`，下載後的檔名是 `IEP_template.odt`）。
2. 用瀏覽器開啟 `SEAM_v1.7.html`。建議使用 Chrome 或 Edge，列印與另存 PDF 的相容性最好。
3. 首次開啟時到「系統設定」填寫學校名稱、特殊教育班班型與科系清單，儲存後即可開始使用。學年度學期預設依日期自動判斷，不必填。
4. 若要匯出 IEP，請在「系統設定 → IEP 模板管理」上傳模板。

## 資料備份與還原

所有資料存放在瀏覽器的 `localStorage`。**清除瀏覽器資料或更換電腦都會讓資料消失**，請養成定期備份的習慣：右下角狀態列會顯示上次備份日期，超過 7 天未備份時，頁面上方會提醒。

| 操作 | 方式 |
|------|------|
| 備份 | 「系統設定」→「備份與還原」→「下載備份」，或右下角狀態列的「備份」，儲存 `.json` 檔 |
| 還原 | 「系統設定」→「備份與還原」→「還原備份」，選取備份的 `.json` 檔 |
| 僅匯入經費 | 匯入格式為 `{"__importType":"budgetOnly", ...}` 的 JSON，只更新經費資料，不影響學生與課表 |
| 清除資料 | 「系統設定」→「備份與還原」→「清除資料」，恢復初始狀態（會問兩次；無法復原，請先備份） |

**升級版本時**：在同一台電腦、同一個瀏覽器開啟新版，通常會沿用原本的資料；但部分瀏覽器會依檔案存放位置分開儲存。請在升級前先匯出備份，若新版中看不到資料，再用「還原備份」還原即可。

## 技術說明

- **架構**：單一 HTML 檔，原生 JavaScript，不依賴任何框架
- **內嵌套件**：JSZip（用於產生 IEP .odt 檔），已內建於檔案中，離線可用
- **儲存**：瀏覽器 `localStorage`。以本機檔案開啟時，同一個瀏覽器裡的 SEAM、IST、SEIA 共用約 5 MB；「系統設定」頁可查看本系統與合計用量
- **字體**：只用電腦內建字型，不連網下載。電腦已安裝思源黑體（Noto Sans TC）與思源宋體（Noto Serif TC）時直接使用（新版 Windows 11 已內建；其他電腦可從 Google Fonts 免費下載安裝），沒有時改用微軟正黑體
- **隱私**：資料只存在使用者本機，不會傳送到任何伺服器；系統沒有任何對外連線

## 系列作品

SEAM 屬於 **SpEdKit 特教工具箱**，由現職特教老師開發，回饋給教學現場。同系列還有 [IST 間接服務紀錄系統](https://github.com/taitungsun/indirect-service-tracker)與 SEIA 特殊教育鑑定評估系統（即將推出；可匯入 SEAM 的學生名單）。三套系統共用相同的設計原則：單一 HTML 檔、免安裝；資料只存在本機、完全不連網；依官方規範建置；可備份、可列印；免費、非商業。介面也一致：相同的頁首頁尾、狀態列與夜間模式，並以圓底單字圖示區分（SEAM「行」、SEIA「鑑」、IST「間」）。
